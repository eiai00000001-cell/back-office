## 2. システムの起動・終了

### 2.1 起動する

デスクトップ等に配置した`起動.app`をダブルクリックしてください。

1. ダブルクリックすると、裏側でシステム(サーバー)が自動的に立ち上がります(通常10秒前後です)。
2. 起動が確認できると、お使いのブラウザ(既定のブラウザ)が自動的に開き、ホーム画面(SC-01)が表示されます。
3. すでにシステムが起動している状態で再度ダブルクリックした場合は、サーバーを起動し直すことはせず、ブラウザが開くだけです(二重起動の心配はありません)。

### 2.2 終了する

デスクトップ等に配置した`終了.app`をダブルクリックしてください。

1. 「システムを終了しました」というメッセージが表示されれば終了は完了です。
2. すでに終了している状態でダブルクリックした場合は、「システムは起動していません」というメッセージが表示されます(エラーにはなりません)。

**重要**: ブラウザのタブを閉じるだけでは、裏側のシステムは終了しません。作業を終えるときは、必ず`終了.app`をダブルクリックしてください(閉じ忘れても、Macを終了・再起動すれば裏側のシステムも一緒に終了します)。

### 2.3 初回起動時に警告が表示された場合

Macのセキュリティ機能により、初めて`起動.app`または`終了.app`を開く際に「開発元を確認できないため開けません」といった警告が表示されることがあります。その場合は、以下の方法で開いてください(2回目以降は警告は表示されません)。

1. アプリのアイコンを右クリック(またはControlキーを押しながらクリック)する。
2. メニューから「開く」を選択する。
3. 表示された確認ダイアログで、再度「開く」を選択する。

## 3. 画面の基本的な見方

- 金額は3桁ごとにカンマ区切りで表示されます(例: 12,000)。
- 日付は「年-月-日」(例: 2026-09-16)の形式で表示・入力します。
- 支払期限を過ぎても入金が確認できていない請求書は、一覧画面上で背景色を変えて目立つように表示されます。
- 入力に誤りがあると、赤字などでエラーメッセージが表示され、保存できません。メッセージの内容に従って入力し直してください。

## 4. ご利用の前に(発行者情報の登録)

請求書・見積書のPDFには、EIAI TEC様ご自身の氏名・屋号・住所・連絡先が印字されます。初めてご利用になる際は、まず「5.11 システム設定画面」から発行者情報を登録してください(未登録のまま請求書を作成しても保存自体は可能ですが、PDF上の発行者欄が空欄になります)。

## 5. 画面ごとの操作

### 5.1 SC-01 ホーム画面

![SC-01 ホーム画面](../02_architect/mockups/SC-01_home.png)

システム起動後、最初に表示される画面です。

| 操作 | 内容 |
|---|---|
| 「請求書」カードをクリック | 請求書一覧画面(5.2)に移動します |
| 「経費管理」カードをクリック | 経費一覧画面(5.6)に移動します |
| 「見積書」カードをクリック | 見積書一覧画面(5.4)に移動します |
| 「売掛金」カードをクリック | 売掛金一覧画面(5.9)に移動します |
| 「システム設定」リンクをクリック | システム設定画面(5.11)に移動します |

画面上部には、未入金の件数・支払期限を過ぎている件数が自動的に表示されます。この件数の取得に失敗した場合は、その部分だけにエラー表示が出ますが、他のカードは通常どおり使用できます。

### 5.2 SC-02 請求書一覧画面

![SC-02 請求書一覧画面](../02_architect/mockups/SC-02_invoice-list.png)

これまでに作成した請求書の一覧を確認できる画面です。

| 操作 | 内容 |
|---|---|
| 「新規作成」ボタン | 新しい請求書の作成画面(5.3)を開きます |
| 一覧の行をクリック | クリックした請求書の詳細画面(5.3)を開きます |
| 取引先・入金ステータスの絞り込み | 条件に合う請求書だけを一覧に表示します |

支払期限を過ぎても入金が確認できていない請求書は、行の背景色を変えて表示されます。

### 5.3 SC-03 請求書詳細・編集画面

![SC-03 請求書詳細・編集画面](../02_architect/mockups/SC-03_invoice-detail.png)

請求書の内容を作成・確認・編集する画面です。入金の記録もこの画面から行います。

**基本情報の入力**

| 項目 | 入力方法 | 備考 |
|---|---|---|
| 取引先 | 一覧から選択 | 未登録の取引先は、選択欄の隣にある「新規登録」リンクから、取引先マスタ管理画面(5.10)を開いて登録できます。登録後は自動的にこの画面に戻り、登録した取引先が選択された状態になります |
| 発行日・支払期限 | カレンダーから選択 | 未入力のまま保存しようとするとエラーになります |
| 請求書番号 | 自動採番(入力不要) | 「発行年+連番」の形式(例: 2026-0001)で自動的に付番されます。手動での変更はできません |

**品目明細の入力**

| 操作 | 内容 |
|---|---|
| 数量・単価を入力 | 入力すると同時に、行ごとの金額、税区分ごとの小計・消費税額、合計金額がその場で自動計算されます |
| 「明細行を追加」ボタン | 空の行が1行追加されます |
| 各行の「削除」ボタン | その行を削除します(品目が0件のまま保存しようとするとエラーになります) |

品目名は必須です。数量・単価は0より大きい数値である必要があります。税区分は「標準10%」「非課税」「不課税」から選びます(軽減税率8%はこのシステムでは扱いません)。

**保存・PDF出力**

| 操作 | 内容 |
|---|---|
| 「保存」ボタン | 入力内容に不備がなければ保存します。新規作成の場合はこのタイミングで請求書番号が確定します |
| 「PDF出力」ボタン | 保存済みの請求書をもとにPDFを作成します(保存前は押せません)。ブラウザの保存・印刷機能でPCに保存したり印刷したりできます |

**入金の記録**

画面下部の入金記録欄から、入金日・入金額を入力して入金を記録できます。入金額の合計が請求金額を超える入力をした場合は、確認メッセージが表示されますので、内容を確認のうえ登録するかどうかを選択してください(過入金や一部返金があった場合を想定した仕様です)。入金額の合計と請求金額の比較により、「未入金」「一部入金」「入金済み」のいずれかが自動的に判定されます。

見積書から変換して作成された請求書には、変換元の見積書番号へのリンクが表示されます。

### 5.5 SC-05 見積書詳細・編集画面

![SC-05 見積書詳細・編集画面](../02_architect/mockups/SC-05_quote-detail.png)

見積書の内容を作成・確認・編集する画面です。基本情報・品目明細の入力方法は請求書詳細画面(5.3)と同じです(支払期限の代わりに「有効期限」を入力します)。

| 操作 | 内容 |
|---|---|
| ステータスの切り替え | 「作成中」「確定」の2段階で管理します。承認・却下のような詳細な段階はありません |
| 「保存」ボタン | 入力内容に不備がなければ保存します |
| 「PDF出力」ボタン | 保存済みの見積書のPDFを作成します |
| 「請求書へ変換」ボタン | この見積書の内容(取引先・品目明細)を引き継いだ新しい請求書を作成し、請求書詳細画面(5.3)に移動します。発行日・支払期限は空欄の状態で作成されるため、請求書側の画面で改めて入力してください |

**ご注意**: 1件の見積書から作成できる請求書は1件までです。すでに変換済みの見積書で再度「請求書へ変換」を押すと、その旨の確認メッセージが表示され、再変換はできません。変換後の請求書と元の見積書はそれぞれ独立して編集でき、一方を直しても他方には反映されません。

### 5.6 SC-06 経費一覧・検索画面

![SC-06 経費一覧・検索画面](../02_architect/mockups/SC-06_expense-list.png)

これまでに記録した経費の一覧を、発生日の新しい順に確認できる画面です。

| 操作 | 内容 |

| 「新規登録」ボタン | 経費登録画面(5.7)を開きます |
| 一覧の行をクリック | クリックした経費の編集画面(5.7)を開きます |
| 領収書アイコンをクリック | 添付済みの領収書ファイルを確認・ダウンロードできます |

### 5.7 SC-07 経費登録・編集画面

![SC-07 経費登録・編集画面](../02_architect/mockups/SC-07_expense-form.png)

経費を1件ずつ登録・編集する画面です。

| 項目 | 入力方法 | 備考 |
|---|---|---|
| 発生日 | カレンダーから選択(必須) | |
| 勘定科目 | 一覧から選択(必須) | 旅費交通費・通信費・消耗品費・水道光熱費・地代家賃・外注工賃・接待交際費・会議費・新聞図書費・支払手数料・租税公課・雑費・その他(自由入力)の13科目から選べます |
| 金額 | 数値入力(必須) | 0より大きい金額を入力してください |
| 税区分 | 一覧から選択(必須) | 標準10%・非課税・不課税・対象外から選びます |
| 支払先・支払方法・メモ | 任意入力 | 支払方法は現金・クレジットカード・銀行振込・その他から選べます |
| 領収書ファイル | ファイル選択またはドラッグ&ドロップ(任意) | 対応形式はjpg/jpeg/png/pdf、サイズは10MBまでです。対応外の形式やサイズ超過のファイルはエラーになり添付できません |

入力後「保存」ボタンを押すと登録されます。

### 5.10 SC-10 取引先マスタ管理画面

![SC-10 取引先マスタ管理画面](../02_architect/mockups/SC-10_client-master.png)

請求書・見積書の発行先となる取引先の情報を登録・編集する画面です。ホーム画面には専用の入り口はなく、請求書・見積書の編集画面(5.3・5.5)にある「新規登録」リンクや、ブラウザのアドレス欄に直接アクセスすることでこの画面を開きます。

| 項目 | 入力方法 | 備考 |
|---|---|---|
| 名称 | テキスト入力(必須) | 会社名・屋号など |
| 郵便番号 | テキスト入力(任意) | 数字とハイフンのみ入力できます |
| 住所・担当者名・連絡先 | テキスト入力(任意) | |

| 操作 | 内容 |
|---|---|
| 「新規登録」ボタン | 登録フォームを表示します |
| 一覧の「編集」操作 | 既存の取引先情報を編集・保存します |

**ご注意**: 現在のバージョンでは、登録した取引先を削除する機能はありません(誤って登録した場合は、名称等を書き換えて再利用するか、開発担当にご相談ください)。

## 6. よく使う操作の流れ

### 6.1 見積書を作成し、確定後に請求書へ変換する

1. ホーム画面(5.1)から「見積書」カードをクリックし、見積書一覧画面(5.4)を開く。
2. 「新規作成」ボタンを押し、見積書詳細画面(5.5)で取引先・発行日・有効期限・品目明細を入力する。
3. 「保存」ボタンを押す(見積書番号が自動採番されます)。
4. 内容が確定したらステータスを「確定」に切り替えて保存する(「作成中」のままでも変換自体は可能です)。
5. 「請求書へ変換」ボタンを押すと、請求書詳細画面(5.3)に移動する。
6. 発行日・支払期限を入力し、「保存」ボタンを押す(請求書番号が新たに自動採番されます)。

### 6.2 請求書に入金を記録する

1. 請求書一覧画面(5.2)または売掛金一覧画面(5.9)から対象の請求書を開く。
2. 画面下部の入金記録欄で、入金日・入金額を入力し「追加」ボタンを押す。
3. 入金額の合計が請求金額に達すると、自動的に「入金済み」のステータスになる。

### 6.3 経費を記録して集計を確認する

1. ホーム画面(5.1)から「経費管理」カードをクリックし、経費一覧画面(5.6)を開く。
2. 「新規登録」ボタンを押し、経費登録画面(5.7)で発生日・勘定科目・金額等を入力する。領収書があれば添付する。
3. 「保存」ボタンを押す。
4. 経費一覧画面から「集計を見る」ボタンを押すと、勘定科目別・月別の集計を確認できる(5.8)。

## 7. 困ったときは

- **画面が正しく表示されない、エラーが頻発する**: 一度`終了.app`でシステムを終了し、`起動.app`で起動し直してみてください。
- **原因不明のエラーが続く**: `backend/logs/uvicorn.log`というファイルに、システム内部で発生したエラーの記録が残る仕組みになっています。開発担当に相談される際は、このファイルの内容もあわせてお伝えいただくと調査がスムーズです。
- **`起動.app`/`終了.app`が開けない(警告が出る)**: 本書2.3章の手順(右クリック→「開く」)をお試しください。
- **データが消えてしまわないか心配**: 現在のバージョンには自動バックアップの仕組みがありません。ご都合のよいタイミングで、`db`フォルダと`data`フォルダを別の場所にコピーしていただくことをおすすめします(詳しくは納品書.md 4章をご参照ください)。
