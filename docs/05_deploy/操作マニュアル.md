## 2. システムの起動・終了

### 2.1 起動する

デスクトップ等に配置した`起動.app`をダブルクリックしてください。

1. ダブルクリックすると、裏側でシステム(サーバー)が自動的に立ち上がります(通常10秒前後です)。
2. 起動が確認できると、お使いのブラウザ(既定のブラウザ)が自動的に開き、ホーム画面(SC-01)が表示されます。
3. すでにシステムが起動している状態で再度ダブルクリックした場合は、サーバーを起動し直すことはせず、ブラウザが開くだけです(二重起動の心配はありません)。

### 2.2 終了する

デスクトップ等に配置した`終了.app`をダブルクリックしてください。

1. 「システムを終了しました」というメッセージが表示されれば終了は完了です。
2. すでに終了している状態でダブルクリックした場合は、「システムは起動していません」というメッセージが表示されます(エラーにはなりません)。

**重要**: ブラウザのタブを閉じるだけでは、裏側のシステムは終了しません。作業を終えるときは、必ず`終了.app`をダブルクリックしてください(閉じ忘れても、Macを終了・再起動すれば裏側のシステムも一緒に終了します)。

### 2.3 初回起動時に警告が表示された場合

Macのセキュリティ機能により、初めて`起動.app`または`終了.app`を開く際に「開発元を確認できないため開けません」といった警告が表示されることがあります。その場合は、以下の方法で開いてください(2回目以降は警告は表示されません)。

1. アプリのアイコンを右クリック(またはControlキーを押しながらクリック)する。
2. メニューから「開く」を選択する。
3. 表示された確認ダイアログで、再度「開く」を選択する。

## 3. 画面の基本的な見方

- 金額は3桁ごとにカンマ区切りで表示されます(例: 12,000)。
- 日付は「年-月-日」(例: 2026-09-16)の形式で表示・入力します。
- 支払期限を過ぎても入金が確認できていない請求書は、一覧画面上で背景色を変えて目立つように表示されます。
- 入力に誤りがあると、赤字などでエラーメッセージが表示され、保存できません。メッセージの内容に従って入力し直してください。

## 4. ご利用の前に(発行者情報の登録)

請求書・見積書のPDFには、EIAI TEC様ご自身の氏名・屋号・住所・連絡先が印字されます。初めてご利用になる際は、まず「5.11 システム設定画面」から発行者情報を登録してください(未登録のまま請求書を作成しても保存自体は可能ですが、PDF上の発行者欄が空欄になります)。

## 5. 画面ごとの操作

### 5.1 SC-01 ホーム画面

![SC-01 ホーム画面(通知エリア・新しいカードを含む)](../02_architect/mockups/SC-01_home.png)

システム起動後、最初に表示される画面です。

| 操作 | 内容 |
|---|---|
| 「請求書」カードをクリック | 請求書一覧画面(5.2)に移動します |
| 「経費管理」カードをクリック | 経費一覧画面(5.6)に移動します |
| 「見積書」カードをクリック | 見積書一覧画面(5.4)に移動します |
| 「売掛金」カードをクリック | 売掛金一覧画面(5.9)に移動します |
| 「財務ダッシュボード」カードをクリック(イテレーション2で追加) | 財務ダッシュボード画面(5.12)に移動します |
| 「案件管理」カードをクリック(イテレーション3で追加) | 案件画面(5.13〜5.15)に移動します |
| 「通知・期限」カードをクリック(イテレーション3で追加) | 通知一覧画面(5.16)に移動します |
| 「レポート出力」カードをクリック(イテレーション3で追加) | レポート出力画面(5.18)に移動します |
| 通知エリアの「確認済み」ボタン(イテレーション3で追加) | その通知を確認済みにして、一覧から消します(5.16参照) |
| 通知エリアの「すべての通知を見る」リンク(イテレーション3で追加) | 通知一覧画面(5.16)に移動します |
| 「システム設定」リンクをクリック | システム設定画面(5.11)に移動します |

画面上部には、未入金の件数・支払期限を過ぎている件数が自動的に表示されます。この件数の取得に失敗した場合は、その部分だけにエラー表示が出ますが、他のカードは通常どおり使用できます。

**ホーム画面の変更点(イテレーション3)**

- サマリー(未入金件数・支払期限超過件数)の下に、**「通知」エリア**が加わりました。期限が近い、または過ぎた項目のうち、未確認のものを上から5件まで表示し、「未確認 ○ 件(うち期限超過 ○ 件)」と件数を示します。表示の順は、期限を過ぎているものが先頭、次に期限の近い順です。
- メニューのカードが3枚(案件管理・通知・期限・レポート出力)増えました。
- 通知エリアの取得に失敗した場合は、通知エリアの部分にだけエラーが表示され、サマリーやメニューのカードは通常どおり使えます。逆にサマリーの取得に失敗しても、通知エリアは表示されます。
- 画面イメージ(設計時の見本)には「経営管理」カードが描かれていますが、この機能は今回の納品に含まれておらず、実際の画面には表示されません(今後の予定です)。

### 5.3 SC-03 請求書詳細・編集画面

![SC-03 請求書詳細・編集画面](../02_architect/mockups/SC-03_invoice-detail.png)

請求書の内容を作成・確認・編集する画面です。入金の記録もこの画面から行います。

**基本情報の入力**

| 項目 | 入力方法 | 備考 |
|---|---|---|
| 取引先 | 一覧から選択 | 未登録の取引先は、選択欄の隣にある「新規登録」リンクから、取引先マスタ管理画面(5.10)を開いて登録できます。登録後は自動的にこの画面に戻り、登録した取引先が選択された状態になります |
| 発行日・支払期限 | カレンダーから選択 | 未入力のまま保存しようとするとエラーになります |
| 案件(イテレーション3で追加) | 一覧から選択(任意) | この請求書を紐付けたい案件を選びます。選ばなくても、従来どおり作成できます。見積書から変換した直後で、発行日・支払期限をまだ入力していない請求書では、案件の変更だけがその場で保存されます |
| 請求書番号 | 自動採番(入力不要) | 「発行年+連番」の形式(例: 2026-0001)で自動的に付番されます。手動での変更はできません |

**品目明細の入力**

| 操作 | 内容 |
|---|---|
| 数量・単価を入力 | 入力すると同時に、行ごとの金額、税区分ごとの小計・消費税額、合計金額がその場で自動計算されます |
| 「明細行を追加」ボタン | 空の行が1行追加されます |
| 各行の「削除」ボタン | その行を削除します(品目が0件のまま保存しようとするとエラーになります) |

品目名は必須です。数量・単価は0より大きい数値である必要があります。税区分は「標準10%」「非課税」「不課税」から選びます(軽減税率8%はこのシステムでは扱いません)。

**保存・PDF出力**

| 操作 | 内容 |
|---|---|
| 「保存」ボタン | 入力内容に不備がなければ保存します。新規作成の場合はこのタイミングで請求書番号が確定します |
| 「PDF出力」ボタン | 保存済みの請求書をもとにPDFを作成します(保存前は押せません)。ブラウザの保存・印刷機能でPCに保存したり印刷したりできます |

**入金の記録**

画面下部の入金記録欄から、入金日・入金額を入力して入金を記録できます。入金額の合計が請求金額を超える入力をした場合は、確認メッセージが表示されますので、内容を確認のうえ登録するかどうかを選択してください(過入金や一部返金があった場合を想定した仕様です)。入金額の合計と請求金額の比較により、「未入金」「一部入金」「入金済み」のいずれかが自動的に判定されます。

見積書から変換して作成された請求書には、変換元の見積書番号へのリンクが表示されます。

### 5.5 SC-05 見積書詳細・編集画面

![SC-05 見積書詳細・編集画面](../02_architect/mockups/SC-05_quote-detail.png)

見積書の内容を作成・確認・編集する画面です。基本情報・品目明細の入力方法は請求書詳細画面(5.3)と同じです(支払期限の代わりに「有効期限」を入力します)。イテレーション3で、請求書と同様に**「案件」欄(任意)**が加わりました。見積書を案件に紐付けたまま「請求書へ変換」すると、変換後の請求書にも同じ案件が引き継がれます。

| 操作 | 内容 |
|---|---|
| ステータスの切り替え | 「作成中」「確定」の2段階で管理します。承認・却下のような詳細な段階はありません |
| 「保存」ボタン | 入力内容に不備がなければ保存します |
| 「PDF出力」ボタン | 保存済みの見積書のPDFを作成します |
| 「請求書へ変換」ボタン | この見積書の内容(取引先・品目明細)を引き継いだ新しい請求書を作成し、請求書詳細画面(5.3)に移動します。発行日・支払期限は空欄の状態で作成されるため、請求書側の画面で改めて入力してください |

**ご注意**: 1件の見積書から作成できる請求書は1件までです。すでに変換済みの見積書で再度「請求書へ変換」を押すと、その旨の確認メッセージが表示され、再変換はできません。変換後の請求書と元の見積書はそれぞれ独立して編集でき、一方を直しても他方には反映されません。

### 5.7 SC-07 経費登録・編集画面

![SC-07 経費登録・編集画面](../02_architect/mockups/SC-07_expense-form.png)

| 項目 | 入力方法 | 備考 |

| 発生日 | カレンダーから選択(必須) | |
| 勘定科目 | 一覧から選択(必須) | 旅費交通費・通信費・消耗品費・水道光熱費・地代家賃・外注工賃・接待交際費・会議費・新聞図書費・支払手数料・租税公課・雑費・その他(自由入力)の13科目から選べます |

### 5.12 SC-12 財務ダッシュボード画面(イテレーション2で新規追加)

![SC-12 財務ダッシュボード画面](../02_architect/mockups/SC-12_financial-dashboard.png)

これまでに登録した請求書・経費・見積書・入金の記録をもとに、売上や利益の状況を自動的に集計してグラフで確認できる画面です。**この画面ではデータの入力・編集はできません(見るだけの画面です)。** 新しく入力したり、金額を修正したりしたい場合は、請求書(5.2〜5.3)・経費(5.6〜5.7)・見積書(5.4〜5.5)の各画面から行ってください。

**画面の開き方**

ホーム画面(5.1)の「財務ダッシュボード」カードをクリックすると開きます。この画面から他の画面への遷移操作はありません(別の画面に移りたいときは、ブラウザの「戻る」またはホーム画面への導線をお使いください)。

**対象期間について**

画面の上部に「対象期間: 直近12ヶ月(例: 2025年10月〜2026年9月)」のように表示されます。表示する期間は常に「今月を含む直近12ヶ月」に自動的に固定されており、期間を指定したり絞り込んだりする操作はありません。月が変わると、表示される期間も自動的に1か月分スライドします。実績(データ)がない月についても、その月を飛ばさずに「0円」または「0件」として表示されますので、12か月分の推移を切れ目なく確認できます。

**4つの区画の見方**

画面は4つの区画(カード)に分かれており、それぞれ別々にデータを取得して表示しています。そのため、万が一いずれか1つの区画が「情報を取得できませんでした」といったエラー表示になった場合でも、他の3つの区画は通常どおり表示され、操作に影響はありません。しばらく待ってから`起動.app`・`終了.app`で再起動するか、あらためて画面を開き直してご確認ください。

| 区画 | 内容 |
|---|---|
| ① 売上・入金状況 | 月ごとの「売上」(請求書を発行した日を基準に集計した金額)と「入金額」(実際にお金を受け取った日を基準に集計した、あくまで参考の金額)を、棒グラフで並べて表示します。直近12ヶ月合計の金額もあわせて表示されます。 |
| ② 経費 | 月ごとの経費合計を棒グラフで、あわせて勘定科目(旅費交通費・消耗品費など)ごとの内訳を円グラフと一覧で表示します。経費は発生日(実際に支出した日)を基準に集計します。 |
| ③ 損益(収支) | 月ごとの「売上-経費」の金額を棒グラフで表示します。黒字の月は緑色、赤字の月は赤色で色分けされ、ひと目で採算の良し悪しを確認できます。 |
| ④ 見積状況 | 月ごとの見積作成件数・見積金額合計を棒グラフで表示するほか、「見積成約率」(見積書を作成した件数のうち、実際に請求書へ変換した割合)を数値(パーセンテージ)で表示します。直近12ヶ月に見積書が1件もない場合、成約率は「-」と表示されます。 |

**ご注意(計算の基準について)**

売上・経費・損益は、いずれも「発生主義」という考え方で計算しています。具体的には、入金があった日ではなく、請求書を発行した日・経費が発生した日を基準に、その月の実績として計上しています。① 区画の「入金額」は、実際にお金が入った日を基準にした参考の情報であり、③ 区画の損益の計算には使われていません。

### 5.16 SC-16 通知一覧画面(イテレーション3・段階2で新規追加)

![SC-16 通知一覧画面](../02_architect/mockups/SC-16_notification-list.png)

期限が近づいた・過ぎた項目を、一か所にまとめて確認する画面です。

**画面の開き方**: ホーム画面(5.1)の「通知・期限」カード、または通知エリアの「すべての通知を見る」をクリックします。

**通知の対象(4種類)**

| 種類 | 通知される場合 |
|---|---|
| 請求書の支払期限 | 未入金または一部入金の請求書 |
| 見積書の有効期限 | まだ請求書へ変換していない見積書 |
| 案件の納期 | 「完了」以外の案件 |
| 登録した期限 | ご自身で登録した期限(5.17参照。確定申告期限、契約更新日など) |

- **期限の7日前から表示され、期限を過ぎても、解消するまで表示され続けます。** 元の項目が解消された場合(入金済みになった、見積書を請求書へ変換した、案件を完了にした、など)は、通知は自動で表示されなくなります。
- 通知は、アプリを開いている間の画面上の表示のみです。メールやスマートフォンには届きません。**起動した時に、ホーム画面で確認する使い方となります。**
- 同じ請求書について、同じ内容の通知が重複して表示されることはありません。請求書一覧の期限超過の強調表示(5.2)は、従来どおり残っています。

| 操作 | 内容 |
|---|---|
| 一覧の内容(下線付きの文字)をクリック | 請求書は請求書詳細(5.3)、見積書は見積書詳細(5.5)、案件は案件詳細(5.15)、登録した期限は期限の一覧(5.17)へ移動します |
| 「確認済み」ボタン | その通知を確認済みにして、一覧から消します |
| 「確認済みも表示」スイッチ | オンにすると、確認済みの通知も薄い色で表示されます。「未確認に戻す」ボタンで、再び未確認に戻せます |
| 「期限を登録・編集」ボタン | 期限の登録・編集画面(5.17)を開きます |
| 「ホームへ」リンク | ホーム画面(5.1)に戻ります |

**見方と注意点**

- 並び順は、期限を過ぎているもの(「超過」の印、赤系の背景)が先頭で、その後は期限の近い順(「接近」の印)です。
- 「確認済み」にしても、**期限日が変更されると、その通知は再び表示されます**。また、期限が近い状態で確認済みにしても、その後に期限を過ぎると、再び表示されます(過ぎた後に確認済みにすると、解消するまで表示されません)。
- 請求書・見積書・案件の期限日を変更した後で元の日付に戻した場合、以前の「確認済み」がそのまま有効になり、再表示されないことがあります。
- 一部の種類だけ取得できなかった場合は、「一部の通知を取得できませんでした(○○)」と表示され、取得できた種類の通知は通常どおり表示されます。
- 「確認済み」を押した時に「対象の通知は既に解消されています」「通知の元データが見つかりません」と表示された場合は、すでに元の項目が入金済みになった、または削除されたことを意味します。一覧が更新されますので、そのままお進みください。

### 5.17 SC-17 期限の登録・編集画面(イテレーション3・段階2で新規追加)

![SC-17 期限の登録・編集画面](../02_architect/mockups/SC-17_deadline-list.png)

確定申告期限や契約更新日など、ご自身で決めた期限を登録して、通知の対象にする画面です。**確定申告書類の作成や契約書の管理を行う機能ではありません。期限の登録と通知のみです。** 確定申告日などの日付は、あらかじめ登録されていませんので、ご自身で入力してください。

**画面の開き方**: 通知一覧(5.16)の「期限を登録・編集」ボタンをクリックします。

**登録した期限の一覧**: 期限日の近い順に、名称・期限日・種別・毎年繰り返し・メモが表示されます。期限を過ぎている、または7日以内のものには「接近」などの印が付きます。

**期限の登録・編集**

「新規登録」ボタン(または各行の「編集」ボタン)を押すと、入力用のダイアログが開きます。

| 項目 | 入力方法 | 備考 |
|---|---|---|
| 名称 | テキスト入力(必須) | 100文字以内です(例: 契約更新(サンプル保守契約)) |
| 期限日 | カレンダーから選択(必須) | 日付の形式で入力してください |
| 種別 | 一覧から選択(必須) | 確定申告・契約更新・その他 |
| メモ | テキスト入力(任意) | 500文字以内です |
| 毎年繰り返す | チェックボックス | チェックすると、翌年以降も同じ月日で通知されます |

|---|---|
| ダイアログの「保存」 | 期限を保存し、一覧に反映します。名称・期限日が未入力の場合は、「名称を入力してください」などのエラーが表示されます |

**「毎年繰り返す」の動き**

- 期限日を過ぎた後で、その通知を「確認済み」にすると、期限日が、今日以降で最も近い翌年以降の同じ月日へ自動的に更新されます(例: 2026-09-01の期限は、確認済みにすると2027-09-01になります)。期限が近い状態で確認済みにしても、期限日は変わりません。
- 「毎年繰り返す」をチェックしていない期限は、期限を過ぎて確認済みにしても、期限日は変わらず、期限の一覧には残ります(不要な場合は「削除」してください)。
- **2月29日の期限は、平年では2月28日へ更新され、その後も2月28日のまま繰り返されます**(うるう年に2月29日へは戻りません)。
- 期限日を変更すると、その期限の「確認済み」は取り消され、通知が再び表示されます。

### 5.18 SC-18 レポート出力画面(イテレーション3・段階2で新規追加)

![SC-18 レポート出力画面](../02_architect/mockups/SC-18_report-export.png)

蓄積したデータを、CSVまたはPDFのファイルとして出力する画面です。

**画面の開き方**: ホーム画面(5.1)の「レポート出力」カードをクリックします。

**操作の流れ**

1. 「1. 出力する種類」で、出力したいレポートを1つ選びます。
2. 「2. 対象期間」で、開始年月と終了年月を選びます。初期値は「今月を含む直近12ヶ月」です。
3. 「月次損益集計レポート」を選んだ場合のみ、「出力形式」でPDFまたはCSVを選びます(それ以外の種類はCSVのみです)。
4. 「出力」ボタンを押します。ファイルがダウンロードされます(ファイル名は「請求書一覧_202510-202609.csv」のような形式です)。

**出力できる7種類**

| 種類 | 形式 | 期間の基準 |
|---|---|---|
| 請求書一覧 | CSV | 請求書の発行日 |
| 入金記録 | CSV | 入金日 |
| 見積書一覧 | CSV | 見積書の発行日 |
| 経費一覧 | CSV | 経費の発生日 |
| 月次損益集計レポート | PDFまたはCSV | 請求書の発行日(売上)・経費の発生日(経費)。財務ダッシュボード(5.12)と同じ集計です |
| 案件別サマリー | CSV | 案件の納期、または紐付いた請求書の発行日 |
| 会計ソフト連携用エクスポート(汎用CSV) | CSV | 売上は発行日、経費は発生日 |

**ご注意**

- 個別の請求書・見積書のPDFは、これまでどおり各詳細画面(5.3・5.5)の「PDF出力」から出力します。
- 期間の指定は、2000年〜2099年の範囲、最大120か月(10年)までです。開始年月が終了年月より後の場合などは、赤字でエラーメッセージが表示され、出力されません。
- 期間内にデータがなかった場合は、「対象期間にデータがありませんでした(項目名のみ出力しました)」のように表示され、項目名だけのファイル(月次損益は全月0円のレポート)が出力されます。
- 出力に失敗した場合は、「出力に失敗しました」と表示されます。もう一度お試しください。
- 発行日が未入力の請求書(見積書から変換した直後で、まだ日付を入力していないもの)は、請求書一覧・売上の集計には含まれません。
- CSVは、UTF-8(BOM付き)・カンマ区切り・改行はCRLFで出力されます。**ExcelやNumbersで開いた時の表示は、まだ確認できていません。** 文字化けするなど、うまく開けない場合は、開発担当へご連絡ください。
- 会計ソフトの連携先はまだ決まっていないため、「会計ソフト連携用エクスポート」は、売上・経費の明細を並べた汎用のCSVです(仕訳の形式ではありません)。特定の会計ソフトにそのまま取り込めるとは限りません。
- 表計算ソフトで開く際の安全のため、セルの先頭が「=」「+」「-」「@」などの文字は、先頭に「'」が付いて出力される場合があります。金額などの数値には付きません。
- **CSV・PDFによる出力は、データのバックアップの代わりにはなりません。** データを守るには、`db`フォルダと`data`フォルダを定期的に別の場所へコピーしてください(7章)。

## 6. よく使う操作の流れ

### 6.1 見積書を作成し、確定後に請求書へ変換する

1. ホーム画面(5.1)から「見積書」カードをクリックし、見積書一覧画面(5.4)を開く。
2. 「新規作成」ボタンを押し、見積書詳細画面(5.5)で取引先・発行日・有効期限・品目明細を入力する。
3. 「保存」ボタンを押す(見積書番号が自動採番されます)。
4. 内容が確定したらステータスを「確定」に切り替えて保存する(「作成中」のままでも変換自体は可能です)。
5. 「請求書へ変換」ボタンを押すと、請求書詳細画面(5.3)に移動する。
6. 発行日・支払期限を入力し、「保存」ボタンを押す(請求書番号が新たに自動採番されます)。

### 6.2 請求書に入金を記録する

1. 請求書一覧画面(5.2)または売掛金一覧画面(5.9)から対象の請求書を開く。
2. 画面下部の入金記録欄で、入金日・入金額を入力し「追加」ボタンを押す。
3. 入金額の合計が請求金額に達すると、自動的に「入金済み」のステータスになる。

### 6.3 経費を記録して集計を確認する

1. ホーム画面(5.1)から「経費管理」カードをクリックし、経費一覧画面(5.6)を開く。
2. 「新規登録」ボタンを押し、経費登録画面(5.7)で発生日・勘定科目・金額等を入力する。領収書があれば添付する。
3. 「保存」ボタンを押す。
4. 経費一覧画面から「集計を見る」ボタンを押すと、勘定科目別・月別の集計を確認できる(5.8)。

### 6.4 全体の経営状況(売上・経費・利益)をまとめて確認する(イテレーション2で新規追加)

1. ホーム画面(5.1)から「財務ダッシュボード」カードをクリックし、財務ダッシュボード画面(5.12)を開く。
2. 「売上・入金状況」区画で、直近12ヶ月の売上・入金額の推移を確認する。
3. 「経費」区画で、月ごとの経費合計と、勘定科目別にどの支出が多いかを確認する。
4. 「損益(収支)」区画で、黒字・赤字の月を色分けで確認する。
5. 「見積状況」区画で、見積作成件数・金額の推移と、見積書がどれだけ実際の受注(請求書)につながっているか(見積成約率)を確認する。

この画面は参照専用のため、内容を修正したい場合は、対応する各画面(請求書・経費・見積書)から入力・修正を行ってください。

### 6.5 案件を登録して、請求書・見積書を紐付ける(イテレーション3で新規追加)

1. ホーム画面(5.1)から「案件管理」カードをクリックし、案件一覧(5.13)を開く。
2. 「新規案件」ボタンを押し、案件詳細画面(5.15)で案件名・取引先・ステータス・納期を入力して「保存」する。
3. 「見積書を紐付ける」または「請求書を紐付ける」ボタンから、対象の書類を選んで「紐付ける」を押す。
4. 「集計サマリー」で、金額・入金済み金額・未回収金額を確認する。
5. 仕事が進んだら、カンバン(5.14)でカードを次の列へ動かして、ステータスを更新する。

### 6.6 期限を登録して、通知で確認する(イテレーション3で新規追加)

1. ホーム画面(5.1)の「通知・期限」カードから通知一覧(5.16)を開き、「期限を登録・編集」ボタンを押す。
2. 期限の登録・編集画面(5.17)で「新規登録」を押し、名称・期限日・種別を入力して「保存」する(毎年必要なものは「毎年繰り返す」にチェックする)。
3. 期限の7日前から、ホーム画面の通知エリアに表示される。内容を確認したら「確認済み」を押す。

### 6.7 月次の損益レポートを出力する(イテレーション3で新規追加)

1. ホーム画面(5.1)の「レポート出力」カードをクリックし、レポート出力画面(5.18)を開く。
2. 「月次損益集計レポート」を選び、対象期間と出力形式(PDFまたはCSV)を選ぶ。
3. 「出力」ボタンを押し、ダウンロードされたファイルを確認する。

## 7. 困ったときは

- **画面が正しく表示されない、エラーが頻発する**: 一度`終了.app`でシステムを終了し、`起動.app`で起動し直してみてください。
- **原因不明のエラーが続く**: `backend/logs/uvicorn.log`というファイルに、システム内部で発生したエラーの記録が残る仕組みになっています。開発担当に相談される際は、このファイルの内容もあわせてお伝えいただくと調査がスムーズです。
- **`起動.app`/`終了.app`が開けない(警告が出る)**: 本書2.3章の手順(右クリック→「開く」)をお試しください。
- **通知一覧やレポート出力の画面が表示されない・ホーム画面に通知エリアがない**: 画面の更新(ビルド)がまだ行われていない可能性があります。納品書.md 5.3章の「フロントエンドの再ビルド」が完了しているかをご確認ください(開発担当にご相談ください)。
- **起動時に「データベースの更新に失敗した」というメッセージが表示された**: システムは起動しません。`backend/logs/uvicorn.log`の内容とあわせて開発担当へご連絡ください。更新前の状態への戻し方は、納品書.md 5.5章をご覧ください。
- **データが消えてしまわないか心配**: 現在のバージョンには自動バックアップの仕組みがありません。ご都合のよいタイミングで、`db`フォルダと`data`フォルダを別の場所にコピーしていただくことをおすすめします(詳しくは納品書.md 4章をご参照ください)。レポート出力(CSV・PDF)はバックアップの代わりにはなりません。
