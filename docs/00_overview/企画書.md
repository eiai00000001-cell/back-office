# 個人事業 事務管理システム 企画書

## 1. 概要

### 1.1 目的
個人事業(EIAI TEC)における事務作業を一元管理するための、自分専用の事務管理システムを開発する。
請求書発行・経費管理・見積書作成・財務ダッシュボード・確定申告対応・契約書テンプレート・経営管理といった
複数の業務を、ホーム画面から選択して行える形にまとめる。

### 1.2 位置づけ
- EIAI TECの「ポートフォリオ=業務基盤」戦略における中核ツール
- 実際の業務効率化に使いながら、AI駆動開発の実績としてGitHubにも公開する想定
- 既存ロードマップ(Tier1: 請求書・経費・見積 / Tier2: 案件管理・財務ダッシュボード / Tier3: 確定申告・契約書)を
  段階分けせず、1つの統合ツールとして企画する

### 1.3 前提条件
- 想定ユーザー:自分専用(EIAI TEC本人のみ利用)
- データ保存:ローカル完結(クラウド同期なし)
- 技術スタック:Python / React(既存の開発方針を踏襲)想定 ※要確認
